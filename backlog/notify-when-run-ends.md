## Problem

A run can take more than half an hour, and the only way to know it ended is to keep looking at the page.

## What to build

- A system notification through the browser when the run finishes or fails (permission is asked once).
- The tab title changes to show "Done" or "Failed".

## Notes

- Decided 2026-11-15: system notification plus tab title; no sound.
